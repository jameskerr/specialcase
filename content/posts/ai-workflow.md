It’s only been 7 months since my coding workflow has completely changed with AI.

It’s taken much trial and error to find the sweet spot, where Claude and I can get into the flow state.

I say it like that because that’s the only way I’ve enjoyed working with it. If I give a large creative task, it will do it, but it’s just not good enough. And then I have to review so much code. I don’t like reviewing complicated code. And AI cannot be trust to do everything without any reviewing in the cases like mine where I’m building a product that needs to work a certain way.

If it takes too long to respond, I lose the flow. If I’m waiting 2+ minutes for example, game over.

If I’m fighting it on design decisions, no good.

It’s great for brainstorming design decisions. But in the end it’s got to be my own design.

I will often write the API in the code that I want then tell Claude to fill in the rest to make it possible.

If I give it small enough tasks that it doesn’t need to think too long, we’re in business. It allows me to think at a high level about my project, rather than worrying the right way to pass a block as an argument.

Refactorings. On my god. It’s lifechaningt to be able to safely rename files, move code. I will do one example, then tell Claude to make all the rest copy that one. So much faster than manually doing that.

I never write tests myself anymore. Before AI, I had spend a good portion of my time making sure tests were fast, readable, and short. Now AI just re-produces more of what was already there. I’m not above 90% coverage and it’s easy to stay there.

The cost gets expensive quick. I use the $20 a month Claude plan and I think the constraint is actually a positive. It makes me not lean on AI too much, it helps me stay engaged and in the flow of coding where I love to be.

That prevents me from setting my effort setting to anything above “high”. If I use xhigh, I blow through my session limit within an hour. There’s nothing worth that being stranded for hours with no AI. I do watch my /usage closely when I’m using high or xhigh. However, if I set it to medium, I don’t need to worry about hitting session limits for the most part. When I do, I don’t need to wait too long before it resets.
