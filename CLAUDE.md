## Project Overview

This is a personal blog built with Hugo static site generator, using a custom theme called "blank". The blog is styled with Tailwind CSS and PostCSS, and is deployed on Netlify.

## Core Commands

### Development Server
```bash
hugo serve -D
```
Starts the Hugo development server with drafts enabled. The VSCode task "start" runs this command.

### Create New Post
```bash
hugo new content/posts/2025/post-slug
```
Creates a new post using the archetype template at `archetypes/posts/index.md`. Posts are organized by year in subdirectories.

### Build Site
```bash
hugo
```
Builds the static site to the `public/` directory.

### CSS Processing
CSS is automatically processed through PostCSS during Hugo builds. Manual PostCSS runs are typically not needed as Hugo handles this via the `postCSS` pipeline in templates.

### Formatting
```bash
npx prettier --write .
```
Formats code using Prettier with go-template plugin for HTML files.

## Architecture

### Content Structure
- **Posts**: Located in `content/posts/`, organized by year in subdirectories (e.g., `content/posts/2025/`)
- **Post Format**: Each post is a directory containing `index.md` and any associated assets (images, etc.)
- **Front Matter**: Posts use YAML front matter with `title`, `date`, `draft`, and `tags` fields

### Theme Structure
The custom "blank" theme is in `themes/blank/`:
- **Layouts**: `layouts/_default/baseof.html` is the base template that includes header/footer partials
- **Shortcodes**: Custom shortcodes in `layouts/shortcodes/` for HTML, notes, poems, and initial caps
- **Partials**: Modular components in `layouts/partials/` (header, footer, sidebar, pagination, subscribe)

### CSS Architecture
CSS follows a layered approach in `assets/css/main.css`:
1. Tailwind base layer
2. Custom reset (`reset.css`)
3. Tailwind components
4. CSS variables (`variables.css`)
5. Global styles (`global.css`)
6. Composition utilities (`compositions.css`)
7. Syntax highlighting (`syntax.css`)
8. Block-level styles (`blocks.css`)
9. Tailwind utilities
10. Custom utilities (`utilities.css`)

### PostCSS Pipeline
Configured in `postcss.config.js`:
- **postcss-import**: Resolves `@import` statements
- **tailwindcss**: Processes Tailwind directives
- **autoprefixer**: Adds vendor prefixes
- **postcss-utopia**: Fluid typography (320px-1080px viewport range)

### Tailwind Configuration
In `tailwind.config.js`:
- Content source: `hugo_stats.json` (generated by Hugo's build stats)
- Preflight disabled (using custom reset)
- Opacity utilities disabled
- "container" class blocklisted

### Build Process
Hugo uses `buildStats` (in `hugo.yaml`) to generate `hugo_stats.json` which tracks all CSS classes used in templates. This enables Tailwind to purge unused styles.

## Deployment

Deployed to Netlify using Hugo version 0.121.0 (specified in `netlify.toml`).

## Hugo Configuration

Key settings in `hugo.yaml`:
- **Theme**: "blank"
- **Pager Size**: 100 posts per page
- **Summary Length**: 20 words
- **Markup**: Goldmark with unsafe HTML enabled for rich content
- **Syntax Highlighting**: Nord theme without inline classes
